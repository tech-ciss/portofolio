# Portfolio CISS TECH

Portfolio professionnel d’Alassane Cissé, développeur Full-Stack basé à Abidjan.

## Technologies

- React 18 et TypeScript
- Vite 8
- Tailwind CSS
- Framer Motion
- React Router
- Vitest et Testing Library

## Installation

Prérequis : Node.js 22.12 ou une version plus récente.

```bash
npm install
npm run dev
```

## Vérifications

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

## Formulaire de contact

Le formulaire utilise FormSubmit et transmet les messages à l’adresse définie dans
`src/lib/site-config.ts`. Après la première mise en ligne, un premier envoi est
nécessaire pour recevoir puis valider l’email d’activation FormSubmit.

## Configuration personnelle

Les coordonnées, liens sociaux et chemin du CV sont centralisés dans
`src/lib/site-config.ts`.
